# 日本の現場で求められる機能と、競合が埋めていない穴

Leinwand を日本の制作・印刷の現場で使えるものにするために、Illustrator の代わりとして名前が挙がる Affinity(Canva)と Inkscape が対応していない部分を洗い出した。仕様書に取り込むかどうかは、この案を見て決める(2026-10-03 時点の調査)。

## 1. 競合の状況

| 項目 | Affinity 3(Canva、2025年に無料化) | Inkscape | Leinwand の予定 |
| --- | --- | --- | --- |
| 縦書き | なし。公式ヘルプで当面対応しないと明言。縦書き用に調整したフォントや1文字ずつの改行で疑似的に組む回避策が出回っている | あるが、長音記号が回らない、約物の位置がずれるなど日本語の縦組みには使えない | フェーズ3 |
| 縦中横、ルビ、禁則、文字組みアキ量 | なし | ほぼなし | フェーズ3(ルビ、圏点、割注はフェーズ4) |
| CMYK・特色 | あり | なし(RGB のみ) | モデルは対応済み。編集と出力はフェーズ4 |
| .ai の読み込み | Illustrator で「PDF互換ファイルを作成」を付けて保存したものだけ(PDF 部分を読む) | PDF 部分を読む | フェーズ3。独自データも読む(`docs/ai-format-notes.md`) |
| .ai での保存 | なし | なし | 予定なし |
| 古い日本語フォント | 一部(DFP フォントなど)が使えないという報告 | — | OS のフォントをそのまま使う |

日本の印刷入稿は今も Illustrator のデータか PDF が中心で、文字はアウトライン化か埋め込みが求められる。印刷会社の入稿テンプレートも .ai で配られることが多い。

## 2. 穴の候補

### A. 日本語組版(いちばん大きな穴。すでにフェーズ3の重点)

| 機能 | 状態 | 提案 |
| --- | --- | --- |
| 縦組み、縦中横、約物の向き、欧文回転 | 仕様書 5、フェーズ3 | そのまま。競合との差がいちばん大きい |
| 禁則(強い / 弱い)、文字組みアキ量、ぶら下がり、文字ツメ | 仕様書 5、フェーズ3 | そのまま |
| ルビ(モノ / グループ / 熟語)、圏点 | フェーズ4 | **フェーズ3に前倒し**を提案。チラシ・教材・同人誌で頻出し、競合にない |
| **合成フォント**(かなと漢字、欧文で別のフォントを組み合わせる) | 仕様書にない | **追加を提案**(フェーズ3)。日本の DTP では定番の機能で、Affinity・Inkscape にはない |
| **異体字セレクタ(IVS)**(人名の「辻」の一点しんにょうなど) | 仕様書にない(字形パネルはフェーズ3) | **追加を提案**(フェーズ3、字形パネルと一緒に)。名刺・賞状・名簿で必要 |
| OpenType の字形切り替え(JIS78 / JIS90 / JIS2004、プロポーショナル) | 仕様書 5 | そのまま |

### B. 印刷入稿

| 機能 | 状態 | 提案 |
| --- | --- | --- |
| **CMYK ドキュメントと PDF/X-1a・X-4 の書き出し** | フェーズ4 | **フェーズ3に前倒し**を提案。フェーズ3の到達点「日本語の印刷物が組める」は、CMYK で入稿できないと現場では満たせない |
| **日本式トンボ**(二重トンボ、センタートンボ)と裁ち落とし | 裁ち落としはあり。トンボは仕様書に明記なし | **追加を提案**(フェーズ2、PDF 書き出しと一緒に)。アートボードの外にトンボを作る機能と、PDF 書き出し時に付ける設定 |
| **入稿チェック(プリフライト)** | 仕様書にない | **追加を提案**。RGB の混入、アウトライン化していない文字、孤立点、細すぎる線(0.1mm 未満)、画像の解像度不足、白のオーバープリント、総インキ量、裁ち落とし不足を一覧で示し、該当オブジェクトを選べるようにする。Illustrator 本体にも弱い部分で、差を付けやすい。フェーズ2で RGB 以外の項目、CMYK と一緒に残りを入れる |
| 特色ライブラリ(DIC、PANTONE) | 仕様書にない | 色見本のデータは各社の権利物なので同梱できない。利用者が手持ちのスウォッチ(.ase など)を読み込めるようにする(フェーズ4) |
| **アウトライン化しても元の文字を残す** | 仕様書にない | **追加を提案**(フェーズ2、M14)。アウトライン化したパスに元のテキストを隠して持たせ、後から文字に戻せる。「入稿用にアウトライン化したら直せなくなる」という定番の悩みを解消する。Illustrator にもない |
| 入稿用のパッケージ(リンク画像とフォント情報をまとめる) | 仕様書にない | 画像の配置に対応するときに追加(フェーズ3以降) |

### C. 日本でよく作るもの

| 機能 | 提案 |
| --- | --- |
| **同人誌・冊子の表紙テンプレート**(ページ数と紙の厚さから背幅を計算し、表1・背・表4と裁ち落とし・トンボを一度に作る) | **追加を提案**(フェーズ2の M11 アートボードと一緒に)。同人誌の市場は大きく、競合に専用の機能はない |
| 日本の判型のプリセット(B 判は JIS、四六判、菊判、A5・B5 の冊子、名刺 91×55、はがき) | 新規作成のプリセットを広げる(フェーズ2) |
| 折りパンフレット(二つ折り、三つ折り、巻き三つ折り)のテンプレート | 面ごとの幅の調整込みで追加を提案(フェーズ3) |
| 縦書きの名刺・年賀状・賞状 | 縦組み(フェーズ3)ができれば作れる。テンプレートを同梱する |

### D. 互換性

| 機能 | 提案 |
| --- | --- |
| .ai の読み込み(印刷会社のテンプレートを開ける) | 予定どおりフェーズ3。独自データを読むので、PDF 部分だけを読む競合より再現度を上げられる |
| PDF 互換の .ai での書き出し | 中身は PDF で、Illustrator で開ける(編集性は一部失われる)。「.ai でください」と言われたときの受け渡し用に、フェーズ4の PDF 書き出しと一緒に検討 |

## 3. 優先度の案

競合との差が大きく、作るのが比較的軽いものから。

1. **フェーズ2に足す**: 日本式トンボ、入稿チェック(RGB 以外の項目)、アウトライン化しても元の文字を残す、同人誌の表紙テンプレート(背幅計算)、日本の判型のプリセット。
2. **フェーズ3を強める**: 合成フォント、IVS、ルビと圏点の前倒し、CMYK と PDF/X の前倒し。フェーズ3を「日本語の印刷物を組んで入稿できる」段階にする。
3. **後のフェーズ**: 特色スウォッチの読み込み、PDF 互換の .ai 書き出し、入稿用パッケージ。
