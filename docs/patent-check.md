# 特許の簡易確認

公開前に、実装済みの機能が Adobe の有効な特許に触れていないかを軽く確かめた記録(2026-10-03)。Google Patents での検索による簡易な確認で、法的な鑑定ではない。気になる点が出たら専門家に相談する。

## 考え方

- 特許の存続期間は出願から20年。Illustrator の基本機能(ペンツール、ダイレクト選択、レイヤー、パスの変形、スマートガイドの原型など)の多くは1990年代〜2000年代前半からあり、当時の特許は切れている。
- 有効な特許は、比較的新しい機能の「特定のやり方」を権利にしているものが多い。請求項(クレーム)の要件をすべて満たさなければ抵触しない。

## これから気をつける機能

- ライブコーナー(角ごとの角丸のウィジェット、フェーズ2): 今回の検索では該当する特許は見つからなかったが、作る前にもう一度調べる。
- スナップの方式を変えるとき(US9442623)。
- パターンブラシの角(US8941661、フェーズ4)。
- シェイプ形成ツール、曲線ツール、パペットワープなど、Illustrator CS5 以降に入った機能は、それぞれ作る前に確認する。

## 商標

- アプリ名、ロゴ、アイコンに Adobe、Illustrator、Spectrum を使わない(仕様書 7章)。
- README と配布ページに「Adobe とは無関係」「Adobe、Illustrator、Spectrum は Adobe Inc. の商標」と書く(M7)。
