# 実装時の合意事項

実装の途中で決めたこと、守ること、知っておくべき制約をまとめる。仕様書(spec.md)には「何を作るか」を、このファイルには「どう作るか」で合意したことを書く。決めた理由や計測値は [m0-verification.md](m0-verification.md) にある。

新しく決めたら、日付と経緯(どのマイルストーンで決めたか)を付けて追記する。仕様書と食い違う内容を書くときは、先に仕様書を直すか、食い違いを報告して確認を取る。

## 描画(render)

- キャンバスは `QQuickRhiItem` で作る。Skia(Ganesh)は Qt Quick が作った `VkDevice` とキューをそのまま使い、新しく作らない。
- Skia はアイテムの描画先テクスチャを毎フレームラップして描き、最後に `SHADER_READ_ONLY_OPTIMAL` へ遷移させる。変えたレイアウトは `QRhiTexture::setNativeLayout` で QRhi に伝える。
- vcpkg の Skia には内部の Vulkan メモリアロケーターがないので、`src/render/vma_allocator.*`(VMA)を渡す。
- PDF を作るときは JPEG のエンコーダーとデコーダーを渡す(`SkPDF::JPEG::MetadataWithCallbacks()`)。渡さないと Skia が PDF を作らない。
- QRhi のヘッダーは Qt 6.8 では `Qt6::GuiPrivate` 経由でしか使えない。Qt のバージョンを上げるときは、この部分の API の変化を確かめる。
- 画面外オブジェクトは描かない(M1 で実装)。変換済みのパスと描画範囲は、オブジェクトの同一性(ポインター)をキーにキャッシュする。モデルが不変なので、編集されたオブジェクトは別のオブジェクトになり、キャッシュが古くなることはない。
- 効果: 10秒間ズームとパンを動かした平均で、1万パスは 7.2ms → 3.65ms、5万パスは 24ms → 11.9ms(58fps)、10万パスは 22.4ms(49fps)。
- 描画結果のタイルキャッシュは後回しにする(2026-10-02 合意)。画面外の除外だけで十分な速さが出ており、タイルの作り直しは「編集でどこが変わったか」に依存するため、M2 のコマンドと取り消しの仕組みが決まってから設計する。

## 編集と取り消し(M2)

- 編集操作は core の `edit.h` に置く。どの操作も、変わった枝だけを作り直し、それ以外のレイヤーとオブジェクトは同じものを共有する。編集されなかったオブジェクトは同一性を保つので、描画のキャッシュが無駄にならない。
- 取り消し履歴(`core/history.h`)は、操作ごとに「操作名とその後のドキュメントと選択」を記録する。ドキュメントは構造共有なので、1手あたりのメモリは変わった部分だけで済む。操作名は表示用の文字列ではなく安定したキー(`move`、`delete` など)で、UI 側で翻訳する。
- 選択だけの変更は取り消しの1手にしない(Illustrator と同じ)。取り消すと、そのときの選択も戻る。
- ドラッグ中はプレビュー用の状態を毎回「ドラッグ前の状態」から計算し、マウスを離したときに1手として記録する。誤差がたまらない。
- グループの移動・変形はグループの行列を更新し、子は書き換えない(仕様書 4.1)。パスと複合パスは座標に焼き込む。線幅は拡大縮小しない(Illustrator の「線幅と効果を拡大・縮小」がオフの状態)。
- グループ解除では、グループの不透明度を子に掛け合わせる。子どうしが重なっていると見た目が変わる(近似)。
- 選択ツールなどの道具のロジックは `src/app/editor`(Qt に依存しない静的ライブラリ)に置き、単体テストを付ける。Qt の入力を変換するのは `CanvasItem` の役目。
- ヒットテストは曲線を折れ線に近似して行う(`geometry/hit_test.h`)。先にバウンディングボックスで候補を絞る。
- Qt Quick は、カーソルが止まっていても毎フレーム合成のホバーイベントを送る。位置が変わっていなければヒットテストをしない(しないと1万オブジェクトで 60fps → 50fps に落ちた)。

**Illustrator 実機と未照合のもの**: 前面へ(Ctrl+])・背面へ(Ctrl+[)が「隣の1つ」を越えるのか「重なっている次のもの」を越えるのか、Alt+ドラッグの複製の挙動、回転できる範囲(コーナーの少し外)、ズームのプリセット、ショートカット全般。

## ライブシェイプと図形ツール(M3)

- ライブシェイプ(`core/shape.h`)は「パラメータ+配置の行列」。図形は中心を原点に定義し、行列は回転・移動・反転だけを持つ。拡大縮小は幅・高さ・半径などのパラメータに入れるので、角丸や線が歪まない。角丸の半径は拡大縮小しても変えない(Illustrator の「角を拡大・縮小」がオフの状態)。
- 形を保てない変形(シアー、多角形やスターの縦横別の拡大縮小)をすると、同じ ID の通常のパスに展開する。取り消しで元のライブシェイプに戻る。直線はどんな変形でも直線なので、常にライブのまま。
- 長方形の角は、角ごとに半径と種類(角丸、逆角丸、面取り)を持つ。半径は辺の長さの半分までに切り詰める。
- 楕円の扇形の角度は、3時の方向から画面上で反時計回りに測る。多角形とスターは頂点が真上を向く。
- 新しい図形は、Illustrator の初期設定と同じ「白の塗り、黒の 1pt の線」(直線は線だけ)で、表示中でロックされていないいちばん手前のレイヤーの最前面に置く。レイヤーパネル(M5)ができたら、選択中のレイヤーに置く。
- 変形パネルの X・Y・W・H は選択範囲の境界(基準点は左上)。角度は、ライブシェイプ1つのときはその角度(反時計回りが正)、それ以外は入力した分だけ回転する。基準点の選択は M5 でパネルと一緒に作る。
- 図形ツールのクリック(ドラッグなし)でのサイズ指定ダイアログはまだない。

**Illustrator 実機と未照合のもの(追加)**: 扇形の角度の向き、多角形をドラッグで描くときの向き、変形パネルの初期の基準点と角度の符号、スターの第2半径の初期比率(外径の半分にした)。

## ペンとダイレクト選択(M4)

- アンカー単位の編集は `geometry/path_edit.h` の純粋関数にまとめ、ツールの操作は `app/editor`(Qt に依存しない)に置く。どちらも単体テストを付ける。ペンツールは仕様書 4.2 の操作表の1行ごとにテストがある。
- ペンのクリックやドラッグは、アンカー1つごとに取り消しの1手になる。描画中に取り消すと、パスが残っている間は描画を続ける。
- ライブシェイプのアンカーを動かす(またはアンカーを足す・消す)と、同じ ID の通常のパスに展開する。取り消すとライブシェイプに戻る。
- アンカーの選択状態は取り消し履歴に入れない(オブジェクトの選択は入る)。取り消し・やり直しでアンカーの選択は解除する。
- 削除の使い分け(Illustrator に合わせる):
  - ダイレクト選択で Delete: 選んだアンカーを、つながるセグメントごと消す。パスは残ったアンカーの並びごとに分かれ、最初の部分が元の ID を引き継ぐ。アンカーが1つだけ残る部分は消す(孤立点を作らない)。すべてのアンカーを選んでいればオブジェクトごと消える。
  - コントロールバーの「アンカーを削除」、アンカーポイントの削除ツール、ペンでのアンカー上クリック: アンカーだけを消し、両隣をつないだままにする(形は変わる)。
- 連結(Ctrl+J)は、背面にあるパスの ID と重ね順を引き継ぐ。端点が同じ位置なら1つのアンカーにまとめる。
- スマートガイド(Ctrl+U、初期設定はオン): 他のオブジェクトのアンカーと中心に吸着し、近くになければ縦・横にそろえて、そろえた相手までマゼンタの線を引く。吸着の距離は選択の許容範囲と同じ表示上 4px。図形を描くとき、ペンでアンカーを置くとき、選択したオブジェクトやアンカーを動かすときに効く。アンカーを動かすときは、ポインタではなくつかんだアンカーを吸着させる。ハンドル、セグメントの変形、ラバーバンドはまだ吸着しない。計測ラベルと交点への吸着はまだない。
- アウトライン表示(Ctrl+Y)は表示の設定で、ドキュメントには保存しない。パスを黒のヘアラインで描き、塗り・線・不透明度・クリップを無視する。
- Illustrator の Windows 版に合わせて Ctrl+Y はアウトライン表示に使い、やり直しは Ctrl+Shift+Z だけにする。
- 一時切り替え: Ctrl を押している間は直前に使った選択系ツール(選択系ツールを選んでいるときは切り替えない)、ペンで Alt を押している間はアンカーポイントツール。ドラッグ中は切り替えず、ドラッグの修飾キーとして扱う。
- ペンのカーソルは、M7 でアイコンがそろうまでの暫定として、十字に記号を添えて描く(`*` 新規パス、`^` ハンドルの削除、`o` 閉じる、`/` 継続・連結、`+`/`-` アンカーの追加・削除)。
- コントロールバー(M5)ができるまで、アンカーへのコマンド(コーナー・スムーズ、アンカーの削除、切断、連結)は右のパネルにボタンで置く。

**Illustrator 実機と未照合のもの(追加)**: ダイレクト選択で Delete を押したときに孤立点を残すか、分かれた後の選択状態、スマートガイドの吸着の優先順位(アンカー、中心、整列)と色、Ctrl を押したときの一時切り替えが選択系ツールの使用中にどう振る舞うか。

## 塗りと線、パネル(M5)

- 開いているドキュメントと編集の状態は `Session`(QML のシングルトン)が持つ。キャンバス(`CanvasItem`)は表示と入力だけを受け持ち、パネル、ツールバー、コントロールバーは `Session` を見る。ドキュメントのタブ(7.1)ができたら、タブごとの `Session` にする。
- パネルが編集するのは、アピアランスのいちばん前の塗りと線(アピアランスパネルはフェーズ3)。グループを選んでいるときは中のオブジェクトすべてを変える。新しく足す塗りは背面側、線は前面側に入れる。
- 塗りと線の変更は、選択中のオブジェクトに加えて、新しく描くオブジェクトの設定にもなる。オブジェクトを選ぶと、その塗りと線(いちばん前のもの)が新しいオブジェクトの設定になる(Illustrator と同じ)。何も選んでいないときは、新しいオブジェクトの設定だけを変える(取り消しの履歴に入らない)。
- スライダーのドラッグとカラーパネルのスペクトルのドラッグは、`Session.beginGesture` と `endGesture` の間を1回の取り消しにまとめる(`History::Amend`)。
- スウォッチを削除すると、それを使っていた色は同じ見た目の通常の色に置き換える(スポットカラーの濃度は混ぜた色にする)。プロセスカラーのスウォッチを適用すると通常の色として塗る(グローバルカラーの区別はモデルにまだない)。スポットカラーは参照として塗る。
- 数値入力欄は単位(pt、px、mm、cm、in、"、pc)と四則演算、括弧を受け付ける(`editor/number_input.h`)。ドキュメントの単位はまだポイント固定。上下キーで1ずつ、Shift で10ずつ増減する。複数のオブジェクトで値が違うときは空欄。
- レイヤーパネルは前面を上に並べる。レイヤーは開いた状態、グループは閉じた状態から始まり、開閉は表示の状態でドキュメントには入れない。オブジェクトの行をクリックすると選択(Shift で追加・解除)、レイヤーの行をクリックすると作業レイヤー(新しいオブジェクトの入る先)になる。ドラッグで並べ替え、レイヤーやグループの行の中央に落とすとその中へ入れる。最後の1枚のレイヤーは削除できない。
- 作業レイヤーが隠れているかロックされているときは、表示中でロックされていないいちばん手前のレイヤーに描く。
- スポイトは、クリックしたオブジェクトのアピアランスをまるごと選択中のオブジェクトへ写す。何も選んでいなければ新しいオブジェクトの設定にする。Shift+クリックの画面の色の採取はまだない。
- 手のひらツール(H)とズームツール(Z、Alt でズームアウト)はキャンバス側で処理する(ドキュメントを変えない)。
- テーマ(ライト / ダーク)はトークンの表を入れ替えるだけで、すべての色がバインディングで追従する。切り替えは環境設定(M7)ができるまでステータスバーに置く。アートボードの周りの色(ペーストボード)はテーマと独立に決める(M1 の合意のまま)。
- 部品(`qml/controls/Sp*.qml`)は Qt Quick Templates の上に作る。スクロールバーとツールチップはまだ Fusion スタイルのものを、トークンから作ったパレットで使う。
- UI フォントの Source Sans 3 はまだ同梱していない(今は OS のフォントに置き換わる)。配布の準備(M7)で同梱する。
- ドッキングは KDDockWidgets をアプリ本体に入れた(`prototypes/dock` は削除)。中央のキャンバスは KDDockWidgets がファイルから作るので、ウィンドウからは `Session.canvas` で参照する。KDDockWidgets のパネルの背景は明るいので、パネルは `SpPanel` で背景を敷く。
- 線パネルの矢印と可変線幅プロファイル、カラーパネルのグレースケールと CMYK はモデルの対応が先に要るので、後のフェーズにする。
- 開発用の起動オプション: `--light`(ライトテーマ)、`--select-all`、`--tabs=layers,swatches`(パネルを前面に)。画面の確認とスクリーンショット用。

**Illustrator 実機と未照合のもの(追加)**: オブジェクトを選んだときに新しいオブジェクトの塗りと線がそれに変わるか(初期設定の「新規オブジェクトに基本アピアランスを適用」との関係)、レイヤーパネルの行のクリックとドラッグの細かな挙動、スポイトが写す範囲の初期設定。

## 保存と読み込み(M6)

ファイル形式は `src/io`(Qt にも Skia にも依存しない)にまとめる。

**.lwd**

- `mimetype` の中身は `application/x-leinwand-document`。ZIP の先頭に無圧縮で置き、形式はこれで判定する(拡張子では判定しない)。
- `document.json` はインデント2、キーの順序はコードで固定(既知のキーのあとに未知のキーを読んだ順で)、既定値と同じフィールドは省く、数値は小数点以下6桁に丸め、整数になる値は小数点を付けない。形式バージョンは 1.0。
- 未知のフィールドは、オブジェクト、レイヤー、アピアランスの項目、スウォッチ、アートボード、設定、トップレベルのそれぞれで JSON のまま保持して書き戻す(`unknown_fields`)。知らない列挙値(例: 新しい描画モード)も未知のフィールドとして残し、モデルには既定値を入れる。
- 知らない種類のオブジェクトとアピアランスの項目(例: フェーズ3の効果)は、JSON のまま `PreservedObject` / `UnknownAppearanceItem` として保持し、同じ位置に書き戻す。読み込みレポートに出す。
- 1.0 より後に足すオブジェクトの種類は、古い版が枠を出せるように `"bounds": [x, y, w, h]` を書くことにする。プレースホルダーは移動・重ね順の変更・削除ができ、移動した場合は保存時に `transform` を持つグループで包む(どの版でも読める)。
- SVG から保持した要素は `"type": "preserved"`(`format`、`data`、`bounds`、`transform`)として .lwd に入る。
- 保存は「一時ファイル(`<名前>.saving`)に書く → 読み直して ZIP と JSON を確かめる → 置き換える」。サムネイルは最初のアートボードを最大 512px で描く。
- 自動保存は2分ごと、変更があったときだけ。設定フォルダ(`AppLocalDataLocation/recovery/`)に、元のファイルのパスを書いた `.json` と一緒に書く。書き出しは別スレッド(不変モデルのスナップショットを渡す)。保存したとき、別の文書を開いたとき、正常に閉じたときに消す。起動時に残っていれば復元するか尋ね、復元した文書は未保存として扱う。
- 未保存の変更があるまま閉じる・新規・開くときは、保存するか尋ねる。変更の有無は取り消し履歴のリビジョン番号で判定する(選択の変更は数えない)。

**SVG**

- SVG のユーザー単位(px)を 1pt として読む(Illustrator と同じ)。ルートの `width`/`height` が物理単位(mm、cm、in、pt、pc)なら、その物理的な大きさを保つ。`viewBox` は `preserveAspectRatio`(既定と `none`)に従って合わせる。
- パスと図形の座標には変形を適用する(線幅、破線、角丸の半径も同じ倍率で変える)。グループは行列を持つ。`rect`(角丸が縦横同じ)と `circle`/`ellipse` はライブシェイプに、`line`/`polyline`/`polygon` はパスにする。
- CSS は `<style>` の要素・クラス・ID・子孫セレクタと `style` 属性に対応し、詳細度と出現順で解決する。対応しないセレクタの規則は読み込みレポートに「破棄」で出す。
- グラデーションは最初の分岐点の単色で近似する(フェーズ2で本対応)。`clip-path` はクリッピンググループに変換する。`mask` と `filter` は読み込まない(レポートに出す)。
- 対応しない要素(`text`、`image`、`use`、`defs` など)は XML のまま保持して同じ位置に書き戻す。CSS で付いていた見た目と、親から継承した塗りと線は、要素自身の属性として書き添える(書き出しではスタイルシートを出さないため)。トップレベルの `defs`、`title`、`metadata` などは最初のレイヤーに入れる。`width`/`height` がある要素(画像など)は枠を表示する。テキストは表示されない(フェーズ2)。
- Inkscape のレイヤー(`inkscape:groupmode="layer"`)はレイヤーにし、書き出しもこの形にする。
- 書き出しは最初のアートボードの範囲、プレゼンテーション属性、小数点以下3桁。複数の塗りや線、項目ごとの描画モードは要素を重ねて表す。SVG で表せないもの(内側・外側の線、CMYK・スポットカラー、新しい版の内容)は書き出す前に一覧で示す。
- 仕様書 6.1 の書き出し設定のうち、今あるのは小数点の桁数と範囲(アートボード / 全体)だけ。スタイルの出力方法、テキストのアウトライン化、画像のリンク、Leinwand のメタデータ、最小化はまだない。

**PNG**

- 最初のアートボードを、72 / 150 / 300 ppi で書き出す。背景は白か透明。

**メニュー**: ファイル、編集、オブジェクト、選択、表示、ウィンドウ、ヘルプを、今ある機能の分だけ置いた。メニューにあるショートカットはメニュー側で定義する(同じキーを `Shortcut` と二重に定義すると、どちらも効かなくなるため)。

**Illustrator 実機と未照合のもの(追加)**: SVG の px を pt として読む扱い、レイヤーの書き出し方(Illustrator は `data-name` を使う)。

## 仕上げとリリース(M7)

- **起動**: スプラッシュは `Splash.qml`。初期化の各段階(ドキュメントの準備、パネルの準備、ウィンドウの作成)が自分の名前を表示する。文言は翻訳ファイルで管理する。
- **ウェルカムスクリーン**: 独立したウィンドウ。新規作成のプリセット(印刷: A4、A3、B5、はがき、名刺。Web。アイコン)とカスタムサイズ(幅、高さ、単位、裁ち落とし)、開く、最近使ったファイル(.lwd はサムネイル付き、グリッド / リスト)。ファイルを指定して起動したときと、環境設定でオフにしたときは出さない。カラーモードは RGB だけ(フェーズ1〜3)。
- **ドキュメントのない状態**: 起動直後や「閉じる」のあとは、ドキュメントのない空のメインウィンドウになる(`Session.hasDocument`)。見本のドキュメントは `--showcase` で開く。
- **アートボードの裁ち落とし**: `Artboard::bleed`(全辺同じ値)。`.lwd` の `"bleed"`。キャンバスに赤い線で示す。
- **環境設定**: JSON(Windows は `%APPDATA%\Leinwand\preferences.json`、macOS は `~/Library/Application Support/Leinwand/`、Linux は `~/.config/leinwand/`)。未知のキーは残す。今ある分類は、一般(キー入力、ラバーバンド、ウェルカムスクリーン)、選択範囲・アンカー表示(許容範囲、アンカーのサイズ)、スマートガイド(許容範囲)、ユーザーインターフェイス(テーマ、言語、UI の拡大率、カンバスカラー)、パフォーマンス(取り消しの回数)、ファイル管理(自動保存の間隔、復元データの保存先)。テキスト、単位、ガイド・グリッド、フォントの分類は、その機能と一緒に足す。UI の拡大率は再起動後に反映する(Qt の起動前に読む)。
- **キーボードショートカット**: コマンドごとに複数のキーを持てる(先頭をメニューに表示する)。初期値は Illustrator に合わせ、変更は `shortcuts.json` に初期値との差分として保存する。セットの書き出しと読み込みができる。ほかのコマンドと重なるキーを設定すると、重なる相手を表示する(設定は受け付ける)。
- **翻訳**: `i18n/leinwand_ja.ts`(日本語)と `leinwand_en.ts`(英語の複数形だけ)。`cmake --build --target update_translations` でソースから更新する。用語は Illustrator の日本語版に合わせる。Qt 自身のダイアログの翻訳(`qt_ja`)も読む。言語を変えるとすぐに切り替わる。
- **アイコン**: 原版の SVG(フィルター付き)から `tools/make_icons.ps1` が Edge のヘッドレスモードで PNG を描き、`.ico` をまとめる(生成物はリポジトリに置く)。16〜32px は影・光・粒子のフィルターを外し、パスとハンドルの線を太くした小サイズ版(`leinwand-icon-small.svg`)を使う。`.lwd` 用の文書アイコン(`leinwand-document.svg`)は、ページの上に小サイズ版の図柄を載せたもので、実行ファイルの2番目のアイコンにする。
- **カーソル**: ツールバーのアイコンから作る(黒に白の縁取り)。ペンは操作に応じた記号を添える。ダイレクト選択は白い矢印を描く。
- **配布物**: `cmake --install` で、Qt(windeployqt)、vcpkg の DLL、MSVC ランタイムの DLL、フォント、ライセンスを集める。描画は Vulkan だけなので、ソフトウェア OpenGL と Direct3D・DXC のシェーダーコンパイラーは入れない(パッケージは約40MB)。
- **Web インストーラー**: GitHub Releases の API(`/repos/thesilver0913/leinwand/releases`)から一覧を取り、`-windows-x64.zip` と `.zip.sha256` を添付したリリースだけを候補にする。既定は最新版で、「他のバージョン...」で選び直せる。パッケージは SHA-256 を確かめてから PowerShell の `Expand-Archive` で展開し、前の版の `bin` などを消してから置く。.lwd を関連付け、.svg・.ai・.pdf は「プログラムから開く」の候補にだけ入れる。ユーザー単位と全ユーザーのどちらにも入れられる。アンインストールで、作ったレジストリのキーは空なら消す。
- **リリース**: `v<版>` のタグを push すると `.github/workflows/release.yml` がビルド、テスト、パッケージ作成をして GitHub Releases に公開する。タグは `CMakeLists.txt` の版と一致させる。
- **試し方**: `tools/package-windows.ps1 -ReleasesUrl http://127.0.0.1:8765/releases.json` で、ローカルのサーバーから取るインストーラーを作れる(`/VERYSILENT /CURRENTUSER` で無人インストールを試せる)。

## macOS 対応

フェーズ2の前に、macOS でビルドとテストが通り、試用版の dmg が作れるところまで進める(2026-10-03 合意)。最初は Apple Silicon(arm64)だけ。

- **描画**: macOS では Qt Quick を Metal で動かし、Skia(Ganesh)は Qt の `MTLDevice` と `MTLCommandQueue` をそのまま使う(`src/render/metal_canvas.*`)。Skia のコマンドバッファーは同じキューに Qt のフレームより先にコミットされるので、Qt がテクスチャを使うときには描き終わっている。Metal のオブジェクトは `const void*` で受け渡すので、Objective-C++ は要らない。Vulkan と VMA は macOS ではビルドしない。
- **数値の読み取り**: Apple の標準ライブラリには double 用の `std::from_chars` がないため、`core::ParseDouble` を通す(macOS では C ロケールの `strtod_l`)。
- **アプリバンドル**: `Leinwand.app`。`src/app/Info.plist.in` で .lwd を文書の種類として宣言し(UTI `io.github.thesilver0913.leinwand.document`)、.svg は「このアプリケーションで開く」の候補にだけ入れる。フォントと Qt の翻訳は `Contents/Resources` に置く。Finder から開いたファイルは引数ではなく `QFileOpenEvent` で届く。
- **アイコン**: Apple のアイコングリッド(1024px の中に 824px のタイル)に合わせ、`tools/make_icons.ps1` が余白付きの `mac-*.png` を描く。`.icns` はビルド時に `iconutil` で作る。文書アイコンは macOS に作らせる(`CFBundleTypeIconSystemGenerated`)。
- **設定フォルダ**: `~/Library/Application Support/Leinwand`。
- **ビルド**: プリセット `macos-release`。最低 macOS 12(Qt 6.8 と同じ)。vcpkg はオーバーレイのトリプレット(`cmake/triplets/arm64-osx.cmake`)で同じ最低バージョンに揃える。Skia は `metal` 機能で入れる。
- **配布**: `tools/package-macos.sh` が `cmake --install`(macdeployqt)、アドホック署名、dmg 作成をする。Developer ID の署名と公証はしない(Apple Developer Program に入るまで)。CI の macOS ジョブは dmg を成果物として上げる(リリースではない)。
- **未対応**: メニューバーはウィンドウ内に出る(macOS 上部のメニューバーではない)。Intel Mac 向けのビルドはまだない。

## .ai の読み込みに向けた調査

- .ai の読み込みは本体の機能として作る(プラグインにはしない。仕様書1章のとおりプラグインAPIは公開しない)。2026-10-03 合意。
- 実物のファイルの解析結果は [ai-format-notes.md](ai-format-notes.md) にある。PDF互換部分だけでも見た目はほぼ再現できるが、画像オブジェクトと不透明マスクが要る。Illustrator 独自のデータ(Zstandard 圧縮、旧仕様と同じ骨組みのテキスト形式)からは、レイヤー、アピアランス、効果、テキストの本文が取れる見込みがある。独自データで読める部分を読み、残りをPDF互換部分で補う方針に決めた(2026-10-03、仕様書 6.1・6.2 と10章を更新)。
- 利用者から受け取ったファイルはリポジトリに入れない。テスト用のファイルは同じ要素を持つものを別に作る。

## UI とドッキング

- パネルのドッキングは KDDockWidgets の Qt Quick 版を使う。見た目は `ViewFactory` のサブクラスで、Spectrum のスタイルを当てた QML に差し替える。
- Illustrator に合わせて、パネルグループはタブを常に表示し、タブがあるときはタイトルバーを隠す(`Flag_AlwaysShowTabs`、`Flag_HideTitleBarWhenTabsVisible`)。
- `InternalFlag_DisableTranslucency` を立てて、ドロップ表示をウィンドウ内に描く(パッチが必要)。Windows の Vulkan では半透明ウィンドウが黒くなるため。
- ドラッグ中はフローティングウィンドウ全体の不透明度を下げ、下のドロップ表示が見えるようにする。今はすべてのフローティングウィンドウが半透明になるので、ドラッグ中のものだけにするのが今後の課題。
- KDDockWidgets がドロップ表示を型名で探すため、差し替える QML のファイル名は `ClassicIndicator.qml` にする。
- パッチは KDDockWidgets 本体への提案を検討する。取り込まれたら FetchContent のバージョンを上げ、パッチを外す。

## デザイン

- Spectrum 2 のトークンは `@adobe/spectrum-tokens` 15.5.0、アイコンは `@adobe/spectrum-css-workflow-icons` 5.0.0 を基準にする。
- トークンは M5 でビルド時に Qt のテーマ定義へ変換する。それまでの試作では、使う値を手で写す(出典のトークン名をコメントに書く)。
- ワークフローアイコンの SVG は色を CSS 変数(`var(--iconPrimary, #222)`)で指定しており、Qt の SVG は読めない。テーマごとに色を置き換えたものを用意する(M5 でトークンの変換と一緒に自動化する)。
- UI フォントの Source Sans 3 と源ノ角ゴシックは OS に入っていない前提で、アプリに同梱する。
- M5 までの暫定: 本体の UI は Qt Quick Controls の Fusion スタイルに、Spectrum 2 ダークのトークン(`src/app/qml/Spectrum.qml`)から作った配色を当てる。部品の作り込みは M5。

## コードの書式

- clang-format は Google スタイルをもとに、1行100桁(`.clang-format`)。バージョンは 23.1.2 に固定する(CI は PyPI の `clang-format==23.1.2`、手元は LLVM 23.1.2)。バージョンが違うと整形結果が変わり、CI の書式チェックが落ちる(Ubuntu 標準の 18 で実際に落ちた)。
- `prototypes/` は M0 の検証用。M1 以降、使うものは `src/` に移し、残りは消す。
